# PharmaCast: AI-Based Medicine Demand Prediction System ## Overview PharmaCast is a decision-support system designed for small and medium-scale pharmacies in Sri Lanka. It leverages historical sales data and machine learning (Linear Regression and SARIMA) to predict monthly medicine demand and provide stock recommendations. ## User Roles * **Pharmacist:** Search medicines, view stock levels, view demand graphs, and get recommendations. * **Admin:** Manage users (approve registrations), upload sales data, and manage medicine records. ## Design Requirements * **Theme:** Medical/Pharmacy (White background, Blue and Green accents). * **Experience:** Extremely simple, clean, and intuitive for users with limited ICT experience. * **Responsiveness:** Mobile-responsive using Bootstrap 5. * **Visuals:** Color-coded stock status (Green, Yellow, Red) and interactive Chart.js graphs. ## Core Features * AI-powered demand forecasting. * Stock order quantity recommendations. * Historical sales data management (CSV/XLSX). * Role-based access control and secure authentication.
